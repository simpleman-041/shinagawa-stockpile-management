# 平常時備蓄管理支援システムのUI・UX評価

2026年11月23日。品川区防災課の職員が、平常時に対象倉庫の在庫・使用期限を確認し、入出庫から避難所の充足確認まで進む場面を想定した評価。

## 評価対象と方法

- Flaskの画面ルート19件と12テンプレートを調査した。倉庫一覧・登録・編集・詳細（日常在庫基準）、品目一覧・登録・編集、避難所一覧・登録・編集（正式目標）、倉庫対応・共有割当、在庫一覧・登録・詳細（訂正、入出庫・履歴、論理削除・復元・統合）、備蓄計算・計算履歴・保存詳細・計算条件管理、参考地図を含む。 [画面ルート](../app/routes/pages.py)
- 要件定義書2.0（2026-11-01）§11・V06・V12を確認し、業務ルールと入出力を維持する範囲で表示・操作を改善した。倉庫候補は既存の倉庫一覧APIの全ページから取得し、共有割当では対象避難所に対応する共有倉庫に限定する。画面設計書の版は資料一覧で未確認のため、画面構成の変更は共通ナビゲーションと既存画面内の改善に留めた。 [要件・設計資料](../local-specs/README.md)
- Nielsenの原則から、状態の可視性、業務用語、一貫性、記憶負担、誤操作防止、エラー回復を確認した。WCAG 2.2から、ラベルと構造（1.3.1・3.3.2）、コントラスト（1.4.3・1.4.11）、リフロー（1.4.10）、キーボード（2.1.1）、本文への移動（2.4.1）、フォーカス（2.4.7・2.4.11）、エラー・状態通知（3.3.1・4.1.3）、名前・役割・値（4.1.2）を判断の観点とした。 [Nielsenの10原則](https://www.nngroup.com/articles/ten-usability-heuristics/) · [WCAG 2.2](https://www.w3.org/TR/WCAG22/) · [WAI-ARIAのコンボボックスパターン](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)

重大度は「重大」が主要業務の停止または重大なデータ影響、「高」が対象の誤選択など重要な業務上の支障、「中」が操作のやり直しや理解の遅れ、「低」が局所的な読みにくさ。優先度1は依頼必須または優先修正、2は既存仕様内で修正、3は追加検証・仕様確認。今回の調査で重大に該当する問題は見つからなかった。

地図の容量計算不可・満杯・超過、計算結果の計算不可と数量0、在庫の期限切れ・接近・未確認について、既存判定を確認した。今回の変更では、それらの値や算入条件、在庫・計算履歴の保存契約を維持している。

## 確認結果

- 専用の架空DBと新規ブラウザプロファイルを使い、WindowsのヘッドレスMicrosoft Edgeで全19画面を開いた。画面とタブの旧名称、共通メニューの現在地を確認した。1280・390・320 CSS pxでページ全体の横はみ出しはなかった。在庫画面は1280・320 CSS pxの画像でも確認した。広い表は表内で横スクロールする。
- Windows／Python 3.15.2で `python -m pytest -q` を実行し、557件成功。API・SQLite、自動テストでの倉庫・避難所・品目の登録・編集、在庫登録・期限訂正・入出庫・論理削除・復元・統合、割当、計算・保存・履歴、地図概要を含む。テスト用DBを使用した。
- Node.js 24.19.0で `node --test --test-isolation=none "tests/*.test.cjs"` を実行し、117件成功。追加した倉庫選択のテストは部分一致、全角・半角、同名と精度を要するID、マウスとキーボード、候補外、解除・リセットを検証した。

| 業務フロー | Edgeで確認した結果 |
|---|---|
| 倉庫を探し、対象の在庫・品目・期限を確認 | 倉庫を住所で検索し、結果から対象倉庫の在庫を開いた。登録名の部分一致と同名候補のIDを確認し、クリック・矢印キーとEnterで選択した。品目名と使用期限・期限接近を確認した |

## 変更ファイル

- 画面と名称は `app/templates/` の既存12テンプレート、共通の `_application.html`、`README.md` を変更した。
- 倉庫選択は `app/templates/_warehouse_picker.html` と `app/static/js/warehouse-picker.js` を追加し、`stocks.js` と `warehouse-settings.js` に接続した。計算式の版表示と根拠表は `calculations.js`、共通・在庫のスタイルは `warehouses.css` と `stocks.css` を更新した。
- `tests/warehouse-picker-ui.test.cjs` を追加し、`tests/calculations-ui.test.cjs` と `tests/warehouse-settings-ui.test.cjs` のDOM代替を新しい画面構成に合わせた。

## 未対応の確認

- WCAG 2.2への適合判定、スクリーンリーダー、実機のタッチ操作、品川区職員による操作時間・誤操作率の計測は今回未実施。利用端末と支援技術が確定した段階で、倉庫選択の候補読み上げ、キーボード移動、地図、広い表を重点的に確認する。
- 旧名称を含む既存の環境変数名、SQLiteファイル名、計算式識別子、GISの内部変数名と過去資料は互換性・履歴のため維持した。DBスキーマ、API、計算処理、業務データの差分はない。
